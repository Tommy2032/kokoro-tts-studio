# 🎙️ Kokoro TTS Studio — Синтез речи на русском языке

Полнофункциональное графическое приложение с современным интерфейсом на русском языке для нейросетевого синтеза речи (Text-to-Speech) на базе модели **Kokoro v1.0 ONNX**.

---

## 🚀 Быстрый запуск

### Способ 1 (В один клик):
Дважды щелкните по файлу **`Запустить.bat`** (или `start_gui.bat`).

### Способ 2 (Через командную строку):
```powershell
python app.py
```
*(Или указав путь к Python: `"C:\Users\MadKalmar\AppData\Local\Python\bin\python.exe" app.py`)*

## 🌟 Основные возможности программы

1. **🇷🇺 Полный интерфейс на русском языке**:
   - Все кнопки, ползунки, подсказки и статусы переведены и интуитивно понятны.
2. **🗣️ 54 уникальных голоса нейросети**:
   - **🇺🇸 Американские женские**: `af_heart` (самый мягкий и популярный), `af_bella`, `af_sarah`, `af_sky`, `af_nicole`, `af_nova`, `af_river` и др.
   - **🇺🇸 Американские мужские**: `am_adam` (глубокий диктор), `am_michael`, `am_liam`, `am_echo`, `am_fenrir`, `am_santa` и др.
   - **🇬🇧 Британские**: `bf_alice`, `bf_emma`, `bm_george` (джентльмен BBC), `bm_daniel`, `bm_fable` и др.
   - **🇯🇵 Японские**: `jf_alpha`, `jf_gongitsune`, `jm_kumo` и др.
   - **🇨🇳 Китайские**: `zf_xiaoxiao`, `zm_yunxi` и др.
   - **🌍 Другие языки**: испанские (`ef_dora`, `em_alex`), французский (`ff_siwis`), итальянские (`if_sara`, `im_nicola`), бразильские, хинди.
   - Поиск по голосам и фильтрация по категориям.
   - Кнопка **«🎧 Прослушать образец этого голоса»** для мгновенного знакомства с тембром.
3. **✨ Смешивание голосов (Voice Blending)**:
   - Создавайте собственные уникальные тембры, смешивая два любых голоса в произвольной пропорции (например: 70% Heart + 30% Adam).
4. **⚙️ Тонкая настройка звучания**:
   - **Скорость речи**: плавная регулировка от 0.5x до 2.0x с кнопкой сброса на 1.0x.
   - **Язык произношения**: автоматическое определение (русский, английский, испанский и др.) либо ручной выбор.
   - **Удаление тишины**: опция Trim silence для естественного склеивания пауз.
5. **🎵 Встроенный плеер и визуализатор**:
   - Озвучивание и мгновенное воспроизведение без зависания интерфейса (многопоточная генерация).
   - Кнопки **«Пауза / Продолжить»** и **«Стоп»**.
   - Перемотка по таймлайну кликом или перетаскиванием ползунка.
   - Регулировка громкости (от 0% до 200%).
   - Анимированный спектральный визуализатор волны речи.
6. **💾 Экспорт и история**:
   - Сохранение в формате **WAV** высокой четкости (24 000 Гц).
   - Таблица истории озвучек с быстрым повторным прослушиванием в один клик.
   - Загрузка текста из файлов `.txt`, `.md`, `.json`, `.csv`.
   - Готовые шаблоны текстов (диалоги, аудиокниги, скороговорки).

## 📜 Консольный скрипт (`tts_simple.py`)

Если вам нужно озвучить текст через командную строку или использовать скрипт в своих проектах:

```python
import soundfile as sf
from kokoro_onnx import Kokoro

# Загрузка модели и голосов
kokoro = Kokoro("kokoro-v1.0.onnx", "voices-v1.0.bin")

# Текст для озвучки из input.txt
with open("input.txt", encoding="utf-8") as f:
    text = f.read()

samples, sr = kokoro.create(
    text,
    voice="af_heart",   # Выбор голоса
    speed=1.0,          # Скорость (0.5 - 2.0)
    lang="ru",          # Язык: "ru", "en-us", "en-gb" и др.
)

sf.write("output.wav", samples, sr)
print("Готово: output.wav")
```

Запуск:
```powershell
python tts_simple.py
```

## 📁 Структура файлов проекта

- **`Запустить.bat`** — Запуск графического интерфейса в 1 клик.
- **`app.py`** — Главное приложение с графическим интерфейсом на PyQt6.
- **`tts_engine.py`** — Движок синтеза Kokoro с каталогом голосов, смешиванием и разбивкой текста.
- **`audio_player.py`** — Модуль воспроизведения звука с перемоткой, громкостью и визуализатором.
- **`tts_simple.py`** — Одиночный скрипт для консольного синтеза из `input.txt` в `output.wav`.
- **`kokoro-v1.0.onnx`** — Нейросетевая модель Kokoro v1.0.
- **`voices-v1.0.bin`** — Библиотека из 54 голосов.
- **`input.txt`** — Пример текстового файла для озвучки.
- **`output.wav`** — Сгенерированный аудиофайл.
